# Synthetischer Nachweis für 2.0.1

Quelle ist ausschließlich `tests/fixtures/employment/synthetic-contract.txt`: frei erfundene Testperson, Anschrift, Datum und Konditionen, kombiniert mit öffentlich benannten Organisationsvarianten als Erkennungsprobe. Kein hochgeladener Originalvertrag und keine echten Personaldaten.

`pseudonymisiertes-ergebnis.txt` enthält die exakten UTF-8-Bytes ohne BOM, deren SHA-256 in `verarbeitungsnachweis.json` und `.pdf` steht. Die PDF bildet denselben Text wie die Vorschau ab, mit denselben A4-/Umbruchregeln. Prüfsumme und extrahierter PDF-Text wurden unabhängig geprüft. Die persönliche Prüfung ist ausdrücklich nicht bestätigt. Das Beispiel ist kein Zertifikat und keine Behauptung vollständiger Anonymität.
